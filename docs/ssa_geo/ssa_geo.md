### Fontes globais de dados topográficos

| Resource | Data Types | Coverage | Key Features | **Website** |
| :--- | :--- | :--- | :--- | :--- |
| **OpenTopography** | LiDAR, DEM, DSM | US, Canada, Australia, Brazil | High-resolution, point clouds, on-demand processing | [opentopography.org](https://opentopography.org) |
| **USGS Earth Explorer** | Satellite imagery, DEM (SRTM, ASTER) | Global | Landsat, MODIS, registration required | [earthexplorer.usgs.gov](https://earthexplorer.usgs.gov) |
| **Natural Earth Data** | Vector, Raster | Global | Public domain, 1:10m/50m/110m scales | [naturalearthdata.com](https://www.naturalearthdata.com) |
| **CGIAR CSI** | DEM (SRTM), Climate, Soil | Global | 90m resolution, merged GDEM/SRTM | [cgiarcsi.community](https://cgiarcsi.community) |
| **Copernicus Browser** | Sentinel-1, Sentinel-2 | Global | Free high-res imagery, registration required | [dataspace.copernicus.eu](https://dataspace.copernicus.eu) |
