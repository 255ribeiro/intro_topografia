## Comparisson method 01

To numerically compare two sets of contour curves from the same location, created by different methods or teams, the most direct approach is to measure the **distance between corresponding lines**.  Since the datasets are from the same place, you can compare them directly without needing to account for different geographic extents. 

The recommended method involves using the **"Distance to nearest hub (points)"** tool in QGIS:

1.  **Filter by Elevation**: For each contour interval you want to compare (e.g., 10m, 20m), create separate layers for that specific elevation from both datasets. 
2.  **Convert to Points**: Use the "Extract vertices" tool on each filtered contour layer. This creates a point for every vertex on the contour lines.
3.  **Calculate Distances**: Run the "Distance to nearest hub (points)" tool. Use the vertices from one dataset as the "Source points layer" and the vertices from the other dataset as the "Hub layer". The tool will calculate the shortest distance from each point in the first set to the nearest point in the second set, adding a "HubDistance" field to the output. 
4.  **Analyze Results**: The output layer will contain the distance between the two datasets for each vertex. You can then use basic statistics (e.g., mean, standard deviation, minimum, maximum) on the "HubDistance" field to get a numerical summary of how far apart the two sets of contours are.

This method provides a robust, quantitative measure of the spatial difference between the two contour datasets.

## Comparisson method 02

[https://www.researchgate.net/post/QGIS_How_to_measure_distance_between_contour_lines_of_the_same_elevation](https://www.researchgate.net/post/QGIS_How_to_measure_distance_between_contour_lines_of_the_same_elevation)

To find the error between two interpolation methods for elevation contour curves in QGIS, follow these steps:

1.  **Generate DEMs**: Use two different interpolation methods (e.g., **IDW** and **TIN**) from the *Processing Toolbox > Interpolation* to create two separate Digital Elevation Models (DEMs) from the same contour dataset. 
2.  **Calculate Difference**: Use the **Raster Calculator** to subtract one DEM from the other (`"DEM_TIN@1" - "DEM_IDW@1"`). The resulting raster will show the spatial distribution of errors between the two methods, where values near zero indicate agreement and larger positive/negative values indicate divergence.
3.  **Analyze Error Statistics**: Use **Raster layer statistics** (via *Properties > Information* or *Processing Toolbox*) on the difference raster to get the mean error, standard deviation, and range, providing a quantitative measure of the discrepancy.

Key differences to consider:
*   **IDW** can create terraced or noisy results as it treats contour lines as points and weights influence by distance. 
*   **TIN** creates a surface from triangles between points and generally preserves contour structure better but can fail with dense data or produce jagged edges.

To measure the error between two existing sets of contour lines generated by different methods in QGIS, without re-interpolating, use the **LineComparison** plugin. 

1.  **Install the Plugin**: Go to *Plugins > Manage and Install Plugins*, search for "LineComparison", and install it. 
2.  **Run the Analysis**: Open the plugin (*Vector > LineComparison > LineComparison*), select one contour layer as the reference and the other as the test layer. 
3.  **Quantify the Error**: The plugin buffers both line layers, rasterizes them, and computes a confusion matrix. It outputs **errors of omission** (parts of the reference lines not matched by the test lines) and **errors of commission** (parts of the test lines not matching the reference), providing a statistical measure of the spatial discrepancy.
